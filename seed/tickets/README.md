# Tickets

One note per ticket, `KEY-###.md`, created with `hive_new_ticket`. Frontmatter: `title`, `status` (`todo`, `in-progress`, `in-review`, `done`, `blocked`), `assignee`, `links` (paths in this context the work depends on). With `tracker: jira` in project.md, tickets are named by their Jira key (e.g. `AX-123.md`), filed with `new-jira`, and carry `jira_reconcile` (`pending` until the developer has moved the ticket in Jira).
